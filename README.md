🚢 Titanic Dataset – Exploratory Data Analysis (EDA)  
A complete **Exploratory Data Analysis (EDA)** project using **Python (Pandas, Matplotlib, Seaborn)**.  
This project discovers **patterns, trends, and anomalies** from the Titanic dataset and generates a **professional PDF report** automatically.  

---

## 🎯 Project Objective  
To perform **data cleaning, visualization, and insight extraction** from the Titanic dataset using Python.

---

## 🧠 Learning Outcome  
✔ Gain skill in finding **patterns, trends, and anomalies**  
✔ Learn how to **analyze real-world datasets**  
✔ Learn **EDA techniques used in interviews & industry**  
✔ Learn how to **automatically generate a PDF report**
